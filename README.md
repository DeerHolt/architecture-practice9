# Планировщик задач

Веб-сервер с REST API для управления задачами (TODO-лист). Позволяет добавлять, редактировать, удалять задачи и отмечать их выполненными. Поддерживает повторяющиеся задачи по правилам: ежедневно и ежегодно.


# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Перед запуском тестов запустите сервер. Затем:
```bash
go test ./tests
```

Директория `web` содержит файлы фронтенда.

## Запуск
```bash
go run main.go
```

Сервер запускается на порту 7540. Открыть в браузере: http://localhost:7540

Переменные окружения:
- `TODO_PORT` — порт сервера (по умолчанию 7540)
- `TODO_DBFILE` — путь к файлу БД (по умолчанию ./scheduler.db)

Задания со звёздочкой не выполнялись.
